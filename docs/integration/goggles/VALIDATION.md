Игровые проверки автоматические: UI кликами человека не управлялся.
MayPlace, события ПКМ, quickMoveStack и dispenser вызывают настоящие игровые пути.
На dedicated-сервере использован FakePlayer. Для удалённого рендера в клиенте
использован отдельный серверный FakePlayer с обычной сетевой синхронизацией,
на клиенте — настоящий RemotePlayer. Его inherited doTick принудительно выполняется
только dev-аудитом, поскольку FakePlayer намеренно не тикает автоматически.
Проверены реальные пакеты инвентаря, TRACKING, entity removal и StartTracking.
Два отдельно запущенных человеческих клиента через TCP не использовались.

Существующий пользовательский `-PauditRuntime` также успешно выполнен без Curios:
NBT clamp, защита от packet flood, C2S/S2C, пауза charge/fade, батарейка,
сохранение активности при уничтожении запасных очков, spectator, последняя единица
заряда, исключение невидимых сущностей, ресурсный reload и отсутствие GL error.
Сам Java-аудит не изменён. Исправлена только его ранняя привязка Gradle callback,
которая мешала запуску до создания Forge-задачи.

Численный `MotionChecks` прошёл: точные длительности/smoothstep, C1-разворот,
совпадение 60/960 FPS, 4000 быстрых выборок без overshoot, остановка на паузе.
Проверка `check_assets.py` сравнивает все 88 кубов/UV с bbmodel с допуском 1e−6
модельного пикселя, восемь групп, pivot/клипы, RGBA/прозрачность, байты встроенных,
входных, ресурсных и JAR-текстур. Результат и SHA-256 релизного JAR — `asset_checks.json`.
`git diff --check` проходит; CRLF-предупреждения Git не являются ошибками diff.

Обычный `gradlew clean build` повторно завершился HTTPS-таймаутом загрузки API
Curios (лог `evidence/build-standard-failed.log`); это не ошибка Java-компиляции.
Финальная чистая сборка использует локальный кэш неизменённых официальных артефактов:
`gradlew -I docs/integration/goggles/cache-maven.init.gradle clean build --console=plain`.
Её результат и упаковка описаны в `evidence/build.log`.
Проверяется, что Java class major=61, Curios/API и dev-аудиты не включены в JAR.
Релиз: `build/libs/thermal_vision_v4.jar`.

## Доказательства и воспроизведение

`evidence/{vanilla|curios}/{client|server}/latest.log` содержит маркеры
`GOGGLES ... AUDIT COMPLETE`. `evidence/thermal-regression.log` содержит `AUDIT COMPLETE`.
Чистая сборка не удаляет эти копии. Команды в README для каждого аудита использовались
с локальным Maven init-script из-за первоначального HTTPS-таймаута Gradle.

В клиентских evidence: 01/09/13 — поднятые очки, 14 — опущенная поза без
затемнения тепловым эффектом (обычный игровой inventory renderer), 03 — наклон/приседание,
04 — первое лицо, 05–08 — reload/resize/fullscreen/GUI, 10 — скрытый Curios,
11/12/16 — измерение/respawn/reconnect, 17–20 — реальная удалённая модель и tracking,
21/22 — стекло и исключение невидимой коровы, 23 — spectator.
`animation.gif` составлен из реально захваченных `motion-*.png` с длительностями
по игровому времени из `motion.csv`; новых поз или промежуточных изображений не синтезировано.

Во время работы первоначальные ошибки dev-harness были исправлены и проверки повторены:
неправильный вызов смены измерения через незаданный портал, преждевременная привязка
Forge runClient, ожидание принятия каждого spam-пакета вопреки rate-limit,
и отсутствие автоматического тика у FakePlayer. Они не являются результатом
последних успешных запусков. Первоначальную сетевую ошибку Maven обошли загрузкой
неизменённых официальных артефактов в локальный кэш; замены API не было.

## Ограничения и не выполненные проверки

- Не установлены сторонние моды с габаритными шлемами и изменёнными living/head
  рендерерами. Их визуальная совместимость не проверена. Curios-модель требует HumanoidModel;
  нестандартную модель пропускает безопасно. Ванильный шлем/skin outer layer проверены.
- Не проведён длительный тест на двух отдельных клиентах по TCP с задержкой/потерями
  и сторонними серверными модами. Сетевой путь в настоящем клиенте с серверным
  тестовым игроком проверен, но это не заменяет такой тест сборки модов.
- Стеклянная сцена проверена на реальном тепловом проходе: heat виден за стеклом,
  невидимая сущность исключена. Все виды воды/частичной прозрачности/шейдерных модов
  и их occlusion semantics не проверены. Исходный тепловой pipeline не переписывался.
- Общий список слотов Curios может изменяться сторонними datapack; тестировалась
  штатная конфигурация этой версии и созданный нашим datapack head.
- Линзы имеют более яркую on-текстуру, отдельное физическое свечение не реализовано.
- Blockbench UI не запускался: соответствие проверено по файлу проекта, Java,
  запечённой игровой модели, UV/PNG и реальным Minecraft кадрам.
